# TravelBook - Travel Package Booking Platform

## Project Description

TravelBook is a web-based travel package booking platform that allows users to explore travel packages, view package details, make bookings, manage their bookings, and view payment information.

The platform also provides an admin dashboard for managing users and bookings.

## Features

- User registration and login
- Travel package browsing
- Package details
- Travel booking
- User dashboard
- Booking history
- Payment interface
- Reviews page
- Contact page
- About page
- FAQ page
- Admin login
- Admin dashboard
- Booking status management
- Booking deletion
- Password hashing
- SQLite database

## Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML
- CSS
- JavaScript
- Werkzeug
